# Toksta

> Toksta is a B2B influencer marketing intelligence platform. It runs a vetted database of
> active LinkedIn and YouTube B2B creators and uses AI agents to search, enrich, and score
> them for fit against a brand's campaign — content fit, audience fit, and post-level
> evidence — then manages campaigns, creator lists, brand monitoring and reporting on top.
> Two machine surfaces are published: a credit-metered REST API (Public API v1) and a
> hosted, OAuth-protected MCP server.

## Authentication

REST: `Authorization: Bearer tk_live_<secret>` on every request, plus
`Content-Type: application/json`. Keys are `tk_live_` + 48 hex characters, shown once at
creation (Toksta stores only a SHA-256 hash). Server-to-server only. Keys may be restricted
to a subset of endpoint families; a scoped key hitting a disallowed route returns 403.

MCP: OAuth 2.0 authorization_code + refresh_token against a Supabase Auth authorization
server, discovered through `/.well-known/oauth-protected-resource` on mcp.toksta.com.

## Conventions an agent must know

- Envelope: success is `{"success":true,"data":...,"meta":{...}}`; errors are
  `{"success":false,"error":{"code","message","details"},"meta":{"request_id","trace_id"}}`.
  Not RFC 9457.
- Async is POLLING ONLY. Webhooks are not available in v1.
- Job IDs are not uniform. `GET /v1/jobs/{id}` accepts PLAIN UUIDs only; content-fit,
  audience-fit and enrichment work is retrieved through its own family results endpoint
  (`content-fit:<uuid>`, `audience-fit:<uuid>`, or the original `creator_ids`). Using the
  wrong endpoint returns 404.
- `POST /v1/jobs/{id}/cancel` requires a JSON body — send `{}`.
- `wait_seconds` (max 30) on results endpoints does a short inline server-side poll.
- Terminal job states: succeeded, failed, canceled, expired. Results expire (30-day
  retention in the published example) and then return 404.
- Pagination is cursor-based: `cursor` + `limit` (1-100, default 50); `meta.next_cursor`.
- Rate limiting: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, and
  `Retry-After` on 429. 20-150 req/min depending on plan.
- Metering: every call may cost credits. `X-Toksta-Credit-Cost` may be returned on billable
  responses; `GET /v1/account/usage` reports balance and consumption. 402
  `INSUFFICIENT_CREDITS` when the balance is short.
- No idempotency key. Do not blindly retry a start-POST — it can charge twice.
- 501 `NOT_IMPLEMENTED` is declared on every operation: a route can be documented before
  its handler is live.
- Workspace routes (`/v1/campaigns`, `/v1/creator-lists`) require a SaaS workspace
  entitlement; dedicated API plans get 403.
